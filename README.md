# ownPortfolio

**ownPortfolio** is my personal portfolio website, created to present my skills,
experience, and approach to frontend development in a clear and practical way.  
The main goal of this project was to demonstrate a broader range of my technical
abilities, code quality, and attention to performance and details.

## About the Project

This portfolio showcases my **side projects**, along with the **technologies and
tools** I used to build them.  
Each project represents real development challenges and solutions, reflecting
how I approach architecture, UI, and optimization.

The portfolio itself was intentionally built with a **lightweight and minimal
setup** to focus on performance, clarity, and maintainability rather than heavy
frameworks or excessive libraries.

## Technologies Used

- **Vite**
- **TypeScript**
- **Sass (SCSS)**
- Minimal third-party libraries
- Small, subtle animations for better user experience

## Key Focus Areas

- Clean and readable code
- High performance and fast loading
- Minimal dependencies
- Responsive layout
- Smooth and unobtrusive animations
- Well-structured project architecture

## Highlights

- Designed to scale easily with new projects
- Optimized for good performance and low bundle size
- Simple, modern UI focused on content
- Clear presentation of skills and technologies
